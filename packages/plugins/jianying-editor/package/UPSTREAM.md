# Provenance

This package is independently authored for Convax from the public
`convax.plugin/6`, `convax.plugin-capability/1`, generation-call, MCP, and JianYing
Deep Link contracts.

The package contains no JianYing application code, credential, browser profile,
private draft database reader, or vendor SDK. The local companion observes only
the running process' open draft lock and transfers host-staged media over a
short-lived loopback server.
